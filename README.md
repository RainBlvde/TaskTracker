TaskTracker

Небольшое fullstack-приложение для управления задачами.

Стек
JavaScript
Node.js
HTML / CSS
Docker

Возможности
создание задач
удаление задач
взаимодействие frontend и backend через API
хранение данных

Запуск проекта
npm install
npm start
Структура проекта

front/ — frontend часть приложения
taskServ.js — backend сервер
Dockerfile — контейнеризация приложения
